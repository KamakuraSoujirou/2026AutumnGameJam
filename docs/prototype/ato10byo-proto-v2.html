あと10秒

謎を解いて、爆弾を相手に押し付けろ。受け取るたびに残り時間は10秒に戻る。

← → ↑ ↓ で選んで、Space か Enter で決定

試作用の設定（展示では隠す想定）
CPUの強さ
勝利条件
パス10回目から持ち時間を1秒ずつ短くする
「あと10秒」の読み上げ

操作説明

P1P2
上下左右を選ぶW A S D↑ ← ↓ →
解除に挑戦Q右Shift か /
  • 爆弾を受け取ったら10秒以内に謎を解いて相手に返す。
  • 間違えると残り時間−2秒。0秒で爆発した側の負け。
  • ラウンドごとに爆弾の仕組みが変わる。第1ラウンドは配線、そのあと暗号と順番スイッチ。
  • パスが続くほど謎は難しくなる。
  • パス5回目からは解除に挑戦できる。ひらめき謎に正解すれば即勝利、外せば即爆発。1ラウンド1回まで。

CPU対戦では、どちらのキーでもP1を操作できます。
