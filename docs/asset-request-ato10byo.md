## 2. 優先度の意味

| 優先度 | 意味 |
| --- | --- |
| A | 必須。これがないと遊べない／展示で見栄えがしない |
| B | あると品質が大きく上がる。Aのあとに作る |
| C | 余裕があれば。なければ文字や色で代用する |

## 3. 共通ルール

### 納品先と形式

- 納品先は、非公開リポジトリ `2026AutumnGameJam-assets`（Unity プロジェクトの `Assets/_PrivateAssets/`）。公開リポジトリには入れない。
- 絵は `Art/`、音は `Audio/`（効果音は `Audio/SE/`、BGMは `Audio/BGM/`、ボイスは `Audio/Voice/`）。
- 絵：PNG（背景は透過なし可、それ以外は透過あり）。**画面は 1920×1080 を基準**。サイズは各素材の欄を参照。
- 音：WAV（44.1kHz、16bit）。BGMは OGG でも可。無音の余白は前後0.05秒以内。ループする音はループ位置で途切れないこと。
- 音量はそろえる：効果音は −12dB 前後、BGMは −18dB 前後（展示会場の騒がしさを想定して、効果音が必ず聞こえること）。

### 命名規則

`種類_内容_番号`（半角英小文字とアンダースコア）。例：`se_cut_01.wav`、`bomb_core.png`、`chr_p1_normal.png`。「素材ID」を接頭辞にしてもよい。

### 権利

- 自作、またはライセンスを明記できる素材のみ。生成AIで作る場合はその旨を納品時に書く。
- 他者が作った素材（フリー素材・購入素材）を使うときは、出典・ライセンスを納品メモに書き、`Assets/_PrivateAssets/ThirdParty/` に置く。
- 既存の作品のキャラクター・ロゴ・楽曲に似せたものは作らない。

### 受け入れの流れ

1. 担当が納品フォルダに置いてプッシュし、依頼書の「状態」を「納品済み」にする。
2. プログラム担当が Unity に取り込み、見た目・音を確認する。
3. 直しがあれば「要修正」にしてコメントを書く。問題なければ「OK」。

状態は **未着手 → 制作中 → 納品済み → 要修正／OK** のどれかで書く。

### 絵のメモ

- 色の見分けがつきにくい人にも分かるように、配線の色は明るさや線の形でも見分けがつくとよい。
- 文字は、プロトタイプと同じ 3 つのフォントを使う予定（Dela Gothic One／DotGothic16／Zen Kaku Gothic New）。フォントのファイルは依頼不要（プログラム側で用意する）。

## 9. 連絡メモ

- 優先度Aだけで、最低限は展示できる状態になる。まずAを全部そろえ、そのあとBに進む。
- 仕様が変わる可能性がある項目：キャラクター数（今は最小限）、時間短縮ボイス（VO-03）。
- 質問や変更は、依頼元（プログラム担当）に連絡する。
